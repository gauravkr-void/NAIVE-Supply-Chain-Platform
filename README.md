# NAIVE — Supply Chain Intelligence & Predictive Analytics Platform

Enterprise-grade, dual-mode Business Intelligence (BI) and Machine Learning Streamlit application featuring a Schema-Agnostic Dynamic Data Ingestion Engine and live Late-Delivery Risk Prediction.

## Quick Start

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Upload your supply chain dataset (`.csv`, `.xlsx`, or `.parquet`) in **0 — Data Studio** to unlock all 7 analytical views, or download the sample schema template from Data Studio to test immediately.
